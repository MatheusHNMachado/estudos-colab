- Operações matemáticas básicas
- Manipulação de strings
- Busca e fatiamento de textos
- Operadores booleanos
- Listas
- Estruturas condicionais
- Laços de repetição

Registrar minha evolução prática em Python, Git e GitHub, criando uma base para futuros projetos em Análise de Dados, AWS e Front-end.

- Python
- Google Colab
- Git
- GitHub
